# Морской бой онлайн

Веб-игра «Морской бой» на Python/FastAPI.

## Возможности
- Регистрация и вход пользователей
- Игра против ИИ
- Мультиплеер через комнаты
- Статистика побед и поражений
- PostgreSQL
- Деплой на Render

## Технологии
Python, FastAPI, SQLAlchemy, PostgreSQL, Jinja2, HTML/CSS/JavaScript, bcrypt, JWT.
